# Task Matrix

بورد کانبان سه‌ستونه (برنامه‌ریزی‌شده / در حال انجام / انجام‌شده) با تم دارک نئون ماتریکسی، افزودن و حذف تسک، و جابجایی با درگ‌اند‌دراپ.

## اجرا

ساده‌ترین راه، باز کردن مستقیم فایل است:

```bash
start index.html
```

برای پایداری بیشتر (فونت‌ها و localStorage) پیشنهاد می‌شود با یک سرور محلی سبک اجرا شود:

```bash
npx serve .
```

یا در VS Code از افزونه‌ی Live Server استفاده کنید (کلیک راست روی `index.html` → Open with Live Server).

## ذخیره‌سازی

وضعیت تسک‌ها در `localStorage` مرورگر ذخیره می‌شود، پس با رفرش صفحه از بین نمی‌رود. این ذخیره‌سازی مخصوص همان مرورگر/دستگاه است.

## توسعه

برای تغییرات بعدی (رنگ‌بندی، افکت‌ها، قابلیت‌های جدید مثل برچسب یا مهلت انجام)، همین‌جا از ترمینال Claude Code داخل VS Code درخواست بدهید؛ کل اپ در یک فایل `index.html` (HTML/CSS/JS خالص، بدون build tool) قرار دارد.
